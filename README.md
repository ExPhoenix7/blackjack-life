# Blackjack Mobile

Basit bir Expo / React Native Blackjack mobil oyunu.

## Calistirma

```bash
npm install
npm start
```

Telefonda Expo Go ile QR kodu okutabilir veya Android emulator varsa:

```bash
npm run android
```

## Oyun

- Bahis sec.
- Dagit ile turu baslat.
- Kart Cek veya Kal.
- Krupiye 17'ye kadar kart ceker.
- Blackjack, bust, kazanma, kaybetme ve beraberlik durumlari vardir.
